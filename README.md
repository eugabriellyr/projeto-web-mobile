# ⚖️ Portfólio Profissional - Advocacia & Consultoria Jurídica

Um site institucional e portfólio profissional desenvolvido para impulsionar a carreira de uma advogada em início de trajetória. O objetivo principal da plataforma é criar uma presença digital sólida, transmitir credibilidade, divulgar os serviços jurídicos prestados e oferecer conteúdos informativos que ajudem a comunidade a entender seus direitos.
